# Jax 跑团群指令

这些指令走本机 OneBot 服务。允许的群里可以直接发指令，无需 @Jax。主人私聊也可以掷骰、搜索和预览推荐卡。只配置一个群时，主人私聊可以查询该群的规则书。

| 在 QQ 里发送 | Jax 的回应 |
| --- | --- |
| `.跑团` | 显示指令 |
| `.r` 或 `.r 3d6+2` | 默认掷 d100，或按表达式掷骰并列出每颗结果 |
| `.ra 侦查 60` | CoC 七版普通技能检定和成功等级 |
| `.r 2d20kh1+4` 或 `.r 2d20kl1+4` | 两颗 d20 取高或取低，再加修正 |
| `.模组 DND 秘野兔踪` 或 `.模组 COC 黑水溪` | 从骰声回响按系统搜索。精确命中显示卡片，多个近似结果列出标题和链接 |
| `.推荐 DND` 或 `.推荐 COC` | 从对应规则系统的候选中选一篇；群卡片采用条目提供的封面 |
| `.规则 DND 借机攻击` | 返回书名、版本、CHM 卷与章节、PDF 页码或文本段号，以及对应原文 |
| `.周荐 周五 20:00 DND` | 主人在目标群启用每周推荐，按北京时间执行 |
| `.周荐 关闭` | 主人在目标群取消订阅 |
| `.周荐 状态` | 查看本群设置和下次推送的北京时间 |
| `.周荐 预览` 或 `.周荐 预览 DND` | 预览下一期，或指定系统看样卡。未订阅也可指定系统预览 |
| `.周荐 周五 20:00 轮换` | 每周在 CoC 和 D&D 之间轮换 |

周荐、预览和单条模组共用同一张卡。顺序固定为模组名称、作者、规则系统、推荐人数、预计时长、发布日期、题材标签、玩家导入、来源。每项占一行，缺值显示“未标注”。图片使用条目封面，放在正文之后。

推送在 Jax 在线时运行，到点后有十分钟发送窗口，跨午夜也适用。选取时跳过最近十次推送选过的条目。同一群、同一期的候选池一致时，预览与推送会选中同一篇。排期和发送记录在配置目录的 `trpg-weekly.sqlite3`。

## 导入规则书

把群里可以查阅的规则书从本机导入。支持 CHM、带文字层的 PDF、UTF-8 TXT 和 Markdown。PDF 使用已安装的 `pdftotext`，扫描件需要先做 OCR。PDF 页码按文件第一页起算。CHM 使用 7-Zip 解包静态章节，按一级目录选卷，每卷可用一次 `--volume`。用 `--seven-zip` 可以指定已有的 7z 可执行文件。

在本机项目目录运行下面的 PowerShell 命令，先将示例中的环境变量设为本机的 Python 解释器、规则书路径、实例配置目录和目标群号。

```powershell
$env:PYTHONPATH = (Resolve-Path ./src).Path
& $env:WHALE_PYTHON -m whale_core.life.rulebooks $env:RULEBOOK_FILE --config-dir $env:WHALE_CONFIG_DIR --group $env:WHALE_GROUP_ID --system DND --edition '5e 2024'
```

导入后可以立即查询。相同群、系统、版本和书名再次导入时，用新版原文替换旧索引。规则索引保存在配置目录的 `trpg-rules.sqlite3`。查模组会把指定的系统和检索词发给骰声回响；骰点、规则书检索和引用均在本机完成。
