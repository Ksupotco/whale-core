# TimlMemBench 中文轨 GPT-4o 试跑与费用估算

记录日期：2026-11-09。**尚未调用 GPT-4o；下列金额是估算，不是账单。**

## 已测量的数据规模

- 官方中文 `raw_native_cases`：117 个样本、860 段原始会话、8,598 条发言、962 个治理/激活案例。
- 会话原文共 193,312 个 Unicode 字符，平均每段 225 字符；案例问题共 35,954 字符，平均每题 37 字符。
- whale-core 当前无精选记忆时，`compose_companion_system()` 生成的基础系统提示约 449 字符；这是实际代码测量值，会随时间字段和项目版本略变。
- 官方语义裁判的 case prompt 在固定探针答案下平均 1,559 字符，共约 150 万字符；正式答案会使该数值变化。
- `evals/timlmembench_native.py` 已在不调用模型的情况下跑完 962 题；普通 `chat` 情节没有形成跨会话 curated 召回。

## 官方标价与假设

- [GPT-4o 官方模型页](https://developers.openai.com/api/docs/models/gpt-4o)：标准文本输入 **$2.50 / 100 万 token**，输出 **$10.00 / 100 万 token**。该页面当前标记为 Deprecated，正式调用前须验证账号仍可使用。
- [GPT-5.4 Mini 官方模型页](https://developers.openai.com/api/docs/models/gpt-5.4-mini)：官方语义裁判所需模型，标准输入 **$0.75 / 100 万 token**，输出 **$4.50 / 100 万 token**。
- 未安装 `tiktoken`，且没有真实 API usage 返回值。下面使用宽的每题 token 假设；不能将 Unicode 字符数当作真实 token 数。
- 不假设缓存命中、Batch 折扣、汇率、税费或平台赠金。每题一次回答调用、一次裁判调用，不包含记忆提取调用、重试和多轮实验。

公式：`费用美元 = 输入 token × 输入单价 / 1,000,000 + 输出 token × 输出单价 / 1,000,000`。

| 场景 | 假设每题 GPT-4o 输入 / 输出 token | 962 题回答费用 | 加官方语义裁判后的合计 |
| --- | --- | ---: | ---: |
| 当前原生结构，无跨会话召回 | 300–700 / 50–150 | $1.20–$3.13 | $1.78–$4.50 |
| 未来平均注入数条精选记忆 | 800–1,700 / 50–150 | $2.41–$5.53 | $2.98–$6.90 |

裁判费用区间为 **$0.58–$1.37**，按每题 500–1,000 输入 token、50–150 输出 token 估计。官方裁判模型的实际推理 token 可能使账单高于此区间。若用 GPT-4o 同时做记忆提取，860 段会话还需单独计费；这部分必须在提取提示和调用粒度固定后估算。

**建议试跑：** 先选覆盖九个维度的约 20 题，保留每次 API 返回的 `prompt_tokens`、`completion_tokens` 与失败/重试次数。按上述极端假设，20 题 GPT-4o 回答约 **$0.03–$0.12**；再加裁判约 **$0.01–$0.03**。用真实 usage 重新按各维度加权外推全量，而不是把首 20 题（可能集中在少数样本）的均值直接乘 962。
